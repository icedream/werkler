## Intent

This project is an attempt to write a flexible tool assisting a software
developer with routine professional tasks at larger software companies.

This long-term includes the following:

- Writing, modifying and fixing code
- Reviewing code
- Rubber-ducking
- Drafting and cross-checking software solution designs
- Writing tickets with proper structuring/phrasing in mind
  - Planning features to turn/split into story tickets, task tickets
- Discovering issues in code to turn them into task and bug tickets
- Roughly estimating ticket efforts (story points)
- Technical documentation, e.g. in wikis
- Reading the developer's chat to suggest ticket creation or documentation in wikis
- Memorizing and reusing information about software or infrastructure software runs on

The tool should be written in Go and be kept somewhat modular - I expect to need to extend it regularly with new or different functionality.
